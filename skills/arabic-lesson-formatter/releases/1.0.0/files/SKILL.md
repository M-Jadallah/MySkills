# منسق الدروس العربية الإسلامية (arabic-lesson-formatter)

## نظرة عامة (Overview)
هذه المهارة مخصصة لتحويل التفريغ الشفهي للدروس العربية الإسلامية من ملفات `.txt` إلى مستندات Word `.docx` منسقة ومخرجة باحترافية عالية جداً، مع تشكيل النص وتطبيق قواعد RTL الدقيقة وتلوين الأقواس باللون البني.

## التبعيات (Dependencies)
- **مكتبة docx لـ Node.js**: مثبتة محلياً في مجلد المهارة لإنشاء ملفات `.docx` بدقة.
- **Node.js**: لتشغيل السكريبت.

## خطوات العمل (Workflow)

### 1. الكشف وتحديد الملفات
- يقوم الوكيل بمسح مجلد `lessons_input/` للبحث عن ملفات تفريغ الدروس بصيغة `.txt`.
- إذا وجد **ملفاً واحداً فقط**: يقوم الوكيل الحالي بمعالجته باتباع خطوات المعالجة أدناه.
- إذا وجد **ملفات متعددة**:
  1. يقوم الوكيل بتعريف وكيل فرعي مخصص (Subagent) يسمى `arabic-lesson-formatter-subagent`.
  2. يقوم بتشغيل وكيل فرعي لكل ملف على حدة، وتزويد كل وكيل بمسار ملف تفريغ واحد ومجلد المخرجات.
  3. يتابع الوكيل الرئيسي تقدم عمل الوكلاء الفرعيين حتى يكتملوا جميعاً.

### 2. خطوات معالجة الملف الواحد (تنفذ بواسطة الوكيل المعني بالملف)
لكل ملف تفريغ:
أ. **قراءة وفهم النص**: قراءة النص بالكامل وفهم سياقه العلمي والشرعي.
ب. **التدقيق والتحرير اللغوي**:
   - إزالة الحشو اللغوي الشفهي (مثل: "يعني"، "طيب"، "تمام"، "كما قلنا") مع الحفاظ التام على المادة العلمية والشرح دون اختصار مخل.
   - تصحيح أخطاء التفريغ الصوتي الشائعة.
   - تحويل الأرقام إلى الأرقام العربية المشرقية (العربية الهندية): `١ ٢ ٣ ٤ ٥ ٦ ٧ ٨ ٩ ٠`.
ج. **التشكيل وضبط النص**:
   - وضع التشكيل الكامل (الضمة، الفتحة، الكسرة، السكون، التنوين) على الكلمات قدر الإمكان.
   - **قاعدة هامة**: إذا كان النص المدخل يحتوي على تشكيل مسبق، يتم استخدامه كما هو وتجنب التعديل عليه، والاكتفاء بتشكيل الأجزاء غير المشكولة.
د. **هيكلة النص إلى JSON انتقالي**:
   يقوم الوكيل ببناء هيكل JSON دقيق وحفظه كملف مؤقت بصيغة `.json` يمثل الدرس، وفقاً للمواصفات التالية:
   - `bookTitle`: عنوان الكتاب (مثال: `"شَرْحُ مَتْنِ «فَتْحِ القَرِيبِ المُجِيبِ»"`).
   - `lessonTitle`: عنوان الدرس (مثال: `"الدَّرْسُ [٤٨]: مُبْطِلَاتُ الصَّلَاةِ"`).
   - `paragraphs`: مصفوفة من الفقرات، وكل فقرة تحتوي على:
     - `type`: نوع الفقرة، ويأخذ أحد القيم التالية:
       - `"heading1"`: للعناوين الرئيسية الحمراء (📌 تَمْهِيدٌ:، العناوين المرقمة مثل ١ ٢ ٣، وخلاصة الدرس ✓ خُلَاصَةُ الدَّرْسِ).
       - `"heading2"`: للعناوين الفرعية الداخلية غير الحمراء (مثل: القَيْدُ الأَوَّلُ:، تَنْبِيهٌ اصطلاحي:).
       - `"summary"`: للفقرات التي تبدأ بكلمة `"خلاصة:"` (تكون عريضة).
       - `"bullet"`: للنقاط التي تبدأ بعلامة `•` (تكتب الـ `•` كحرف نصي عادي).
       - `"closing"`: لفقرة الختام الأخيرة (مثل: `"وَاللهُ أَعْلَمُ..."` أو `"وَصَلَّى اللهُ وَسَلَّمَ..."`).
       - `"paragraph"`: للنص العادي الشارح.
     - `text`: النص الكامل للفقرة مشكولاً ومعدلاً لغوياً.

هـ. **توليد مستند Word**:
   - استدعاء سكريبت Node.js المنسق لتوليد الملف:
     ```bash
     node .agents/skills/arabic-lesson-formatter/formatter.js --input <temp_json_path> --output lessons_output/<lesson_name>.docx
     ```
   - التحقق من نجاح التوليد وحذف الملف الانتقالي المؤقت.

## نموذج هيكل الـ JSON المطلوب (JSON Structure Reference)

```json
{
  "bookTitle": "عنوان الكتاب هنا مشكولاً",
  "lessonTitle": "عنوان الدرس [مع أرقام بين أقواس مربعة]",
  "paragraphs": [
    {
      "type": "heading1",
      "text": "📌 تَمْهِيدٌ:"
    },
    {
      "type": "paragraph",
      "text": "نص التمهيد هنا مشكولاً..."
    },
    {
      "type": "heading1",
      "text": "١ أَوَّلًا: عُنْوَانُ القِسْمِ الرَّئِيسِيِّ"
    },
    {
      "type": "summary",
      "text": "خلاصة: الخلاصة العريضة للقسم..."
    },
    {
      "type": "heading2",
      "text": "عُنْوَانٌ فَرْعِيٌّ دَاخِلِيٌّ"
    },
    {
      "type": "bullet",
      "text": "• نقطة مشكولة توضح فكرة فرعية."
    },
    {
      "type": "closing",
      "text": "وَاللهُ أَعْلَمُ، وَصَلَّى اللهُ عَلَى نَبِيِّنَا مُحَمَّدٍ وَآلِهِ وَصَحْبِهِ وَسَلَّمَ."
    }
  ]
}
```

## التعلم الذاتي وحل المشاكل (Self-Correction & Learning Rules)
إذا واجه الوكيل الفرعي أو الرئيسي أي خطأ أثناء تشغيل السكريبت أو بناء الكود:
1. يجب تحليل رسالة الخطأ بدقة.
2. تعديل الكود في `formatter.js` لحل المشكلة بشكل جذري وجعل الكود أكثر مرونة وموثوقية لمنع تكرار الخطأ.
3. مواصلة المعالجة وإعادة التشغيل.
