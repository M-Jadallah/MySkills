# قالب المشروع المتكامل — مختبر الطيف للكيمياء

منهجية: **درس درس**، بالترتيب الصحيح لكتاب الكيمياء الأردني، والمدرس يحدد رقم وموقع كل درس.

## البنية التقنية
```
chem-spectrum-lab/
├── frontend/                 ← ما نبنيه الآن
│   ├── index.html            ← الرئيسية
│   ├── about.html            ← عن المختبر
│   ├── contact.html          ← التواصل
│   ├── lessons.html          ← قائمة الدروس (مرتبة حسب الكتاب)
│   ├── css/site.css
│   ├── shared/               ← أصول مشتركة (مصدر واحد للهوية)
│   │   ├── storage.js        ← ChemLabStorage (LocalStorage)
│   │   ├── layout.js         ← حقن الرأس/التذييل + الترحيب + الاسم + الثيم
│   │   ├── nav.js            ← سابق/تالي + شريط تقدم (داخل المختبر)
│   │   ├── lessons-data.js   ← LESSONS[] (يولّده السكافولد)
│   │   └── theme.css
│   ├── lessons/
│   │   └── lesson-XX/        ← من المهارة 03 (يشير إلى ../../shared)
│   └── assets/               ← logo.png / logo-dark.png
├── backend/                  ← محجوز للتطوير المستقبلي
├── database/                 ← محجوز للتطوير المستقبلي
├── docker/                   ← من المهارة 03 (أول درس فقط)
└── README.md
```

## 1. الصفحات الرئيسية
- **index.html:** شعار + "الفهم قبل الحفظ" + "استكشف الدروس" + اسم المدرس/أرقامه + بطاقات تعريفية.
- **about.html:** قصة المختبر + فلسفة "الفهم قبل الحفظ" + نبذة عن المدرس + الرؤية والرسالة.
- **contact.html:** 📞 0788521514 — 💬 +962 78 852 1514 + الاسم الكامل.
- **lessons.html:** الدروس مرتبة حسب الكتاب؛ بطاقة لكل درس (صورة مصغرة + عنوان + "ادخل المختبر")؛ علامة "مكتمل" للمنجَز.

## 2. عناصر مشتركة (كل صفحة)
- **الرأس:** شعار + تنقّل + زر ثيم + اسم الطالب.
- **التذييل:** حقوق + أرقام التواصل.
- **الشريط الجانبي (داخل المختبر):** عنوان الدرس + سابق/تالي + شريط تقدم.

## 3. شاشة الترحيب
عند أول زيارة: "مرحباً بك في مختبر الطيف!" + "ما اسمك؟" + حقل + "ابدأ الرحلة" + "تخطي". الاسم في LocalStorage ويظهر بالأعلى.

## 4. نظام التخزين (العقد البرمجي)
```javascript
const ChemLabStorage = {
  getUserName(), setUserName(name),
  getProgress(), markLessonComplete(lessonId),
  getTheme(), setTheme(theme),
  getLastLesson(), setLastLesson(lessonId)
  // لاحقاً: API Calls
};
```

## 5. التبديل داكن/فاتح
زر أعلى اليمين؛ الاختيار في LocalStorage؛ يطبّق متغيّرات CSS المختلفة.

## 6. التنقّل بين الدروس
داخل كل مختبر: "قائمة الدروس" + "السابق" (←) + "التالي" (→) + شريط تقدم.

## 7. التوسع المستقبلي (محجوز)
- تسجيل دخول احترافي (JWT + OAuth)
- داش بورد أدمن
- شرح نظري + فيديوهات
- PostgreSQL + Backend Node.js/Python

## ⚠️ قواعد صارمة
- **درس درس** — لا تضف أكثر من درس واحد في المرة.
- **ترتيب الكتاب** — نفس ترتيب الكتاب الأردني.
- **المدرس يحدد الموقع** — أنت تُخبر أين يوضع الدرس ورقمه.
- **هوية موحدة** — نفس الرأس والتذييل في كل صفحة.
- **التخزين المحلي** — LocalStorage الآن، API لاحقاً.
- **الاسم اختياري** — يمكن تخطّيه.
