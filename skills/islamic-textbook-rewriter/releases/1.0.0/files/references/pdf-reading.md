# قراءة كتاب PDF من النص وصور الصفحات

## قبول الملف مباشرة

هذا مسار أصيل للمهارة: PDF نصي أو ممسوح ضوئيًا أو مختلط. لا تشترط تحويل المستخدم
ملفه إلى TXT؛ سكربت التحضير يحفظ النص المتاح ويرندر صور الصفحات، والوكيل يفهم الصور
باستخدام أداة عرض الصور. لا يحلل السكربت المعنى ولا ينفذ OCR تلقائيًا.

أعد استخدام PDF مرفق أو مسار المستخدم. لا تطلب نسخة أخرى إلا إذا كان الملف تالفًا أو
مقفلًا أو كانت دقة أصله تمنع قراءة مواضع لازمة بعد التكبير. لا تغيّر الملف الأصلي.

## التحضير

```powershell
python "<skill-dir>/scripts/prepare_pdf.py" --input "<absolute-path>/book.pdf" --output-dir "<absolute-path>/pdf-reading" --dpi ٢٠٠
```

استخدم Python الذي تتوفر فيه مكتبات المهارة. عند الحاجة اكتشف تبعيات مساحة العمل
بالأداة المخصصة، أو ثبّت التبعية المطلوبة فقط من requirements.txt.
الصفحات في الوسائط تبدأ من ١، وتقبل الأرقام العربية والإنجليزية. للدفعات:

```powershell
python "<skill-dir>/scripts/prepare_pdf.py" --input "<absolute-path>/book.pdf" --output-dir "<absolute-path>/pdf-reading" --pages "١-٨"
```

المخرجات:

- `page-0001.png` وما بعدها: صفحة كاملة، بما فيها التعليقات المرئية، مع الحفاظ على دورانها.
- `page-0001.txt`: نص طبقة PDF الخام إن وجد؛ قد يكون ناقصًا أو معكوس الترتيب.
- `page-0001.blocks.json`: مواقع كتل النص، للمساعدة على ربط النص بمواضعه في الصورة.
- `manifest.json`: مصدر الملف وبصمته وعدد الصفحات والصور ودفعات التغطية. مؤشر طبقة
  النص وصفي فقط، ولا يثبت خلو الصفحة من المادة إذا كان النص المستخرج فارغًا.
- `review-log.json`: سجل لكل صفحة يبدأ بـ`pending`. **لا تغيره إلى `reviewed` إلا بعد
  فتح الصورة وقراءة الصفحة بالفعل**. النجاح البرمجي في إنشاء PNG لا يحدث هذا التغيير.

السكربت يحفظ الصفحات السابقة عند تحضير دفعة أخرى من الملف نفسه. إذا تغير المصدر أو
بصمته، استخدم مجلد قراءة جديدًا حتى لا تخلط صور نسخة بغيرها.

## القراءة البصرية الفعلية

١. افتح صور الصفحات باستخدام `view_image` أو أداة معاينة الصور المتاحة. اقرأ جميع صفحات
النطاق؛ إذا طلب المستخدم الكتاب كله، يتضمن ذلك الغلاف والفهرس والصفحات التمهيدية لتحديد
البيانات والحدود، ثم صفحات المحتوى. راجع على دفعات صغيرة تسمح بقراءة النص بحجمه المناسب؛
صورة مصغرة تجمع عشرات الصفحات تصلح للفهرسة، ولا تغني عن قراءة الصور الكاملة.

٢. في PDF النصي، اقرأ النص الخام مع الصورة ثم صحح ترتيب الفقرات بصريًا. وفي PDF
المصور، استخرج محتواه بالنظر إلى الصور مباشرة حتى لو كانت جميع ملفات TXT فارغة.
إذا استُخدم OCR اختياري متاح لدعم التفريغ، فالصور هي المرجع لتصحيح أخطائه، خصوصًا
في الآيات والأحاديث والحركات والحواشي والمصطلحات.

٣. انتبه إلى ترتيب العربية من اليمين إلى اليسار، وتعدد الأعمدة، وبداية الفقرة واستمرارها
في الصفحة التالية. انقل الجداول بعلاقة الصف والأعمدة، والمربع الجانبي تحت موضوعه،
والأهداف والمفردات والتقويم والأنشطة دون إسقاط. الرسوم التعليمية والخرائط الأصلية
مصدر للمعلومات؛ استخلص علاقاتها وأعد بناءها قابلة للتحرير، ولا تستنتج شيئًا من الرسم
لا يعرضه الكتاب. الصور الزخرفية لا يلزم نقلها.

٤. رقما الصفحة مختلفان: `pdf_page` هو موقع الصفحة داخل الملف، و`printed_page` هو الرقم
المطبوع الذي تقرأه في الصورة. دوّن الثاني إن ظهر، ولا تستنتجه بإزاحة ثابتة دون فحص.
حدد الدرس والصفحات التي يبدأ وينتهي فيها، واربط الفقرات الممتدة بين دفعتين قبل الصياغة.

٥. للنص الصغير أعد رندر الصفحة بدقة ٣٠٠ نقطة، أو قص المنطقة المطلوبة:

```powershell
python "<skill-dir>/scripts/prepare_pdf.py" --input "<absolute-path>/book.pdf" --output-dir "<absolute-path>/pdf-reading" --pages "١٢" --dpi ٣٠٠
python "<skill-dir>/scripts/prepare_pdf.py" --input "<absolute-path>/book.pdf" --output-dir "<absolute-path>/pdf-reading" --pages "١٢" --crop "٠,٠.٥,١,١" --dpi ٣٠٠
```

`--crop` نسب من عرض وارتفاع الصفحة: `left,top,right,bottom` بين ٠ و١، وأصل الإحداثيات
أعلى اليسار. المثال يعرض النصف السفلي. ينتج القص ملفًا إضافيًا؛ لا يستبدل الصورة الكاملة
ولا يحتسبها مقروءة. تفحص الصورة الأصلية أيضًا للحفاظ على السياق.
تكبير الصورة لا يعيد تفاصيل مفقودة من مسح رديء. إن بقي موضع غير مقروء، ضع `unclear`
مع الموضع والسبب في السجل، وأبلغ المستخدم بالنقص. تابع الصفحات الأخرى، ولا تخمّن النص
ولا تعلن اكتمال درس يتوقف على هذا الموضع.

## سجل التغطية والبوابة

يعدّل الوكيل `review-log.json` بعد القراءة، مثل:

```json
{
  "source_sha256": "بصمة الملف الموجودة في manifest.json",
  "pages": [
    {"pdf_page": 1, "status": "reviewed", "printed_page": "٣", "lessons": ["التوبة"], "notes": "قُرئت الصفحة والمربع الجانبي"},
    {"pdf_page": 2, "status": "unclear", "notes": "السطر الأخير غير مقروء في الأصل"}
  ]
}
```

احتفظ بجميع إدخالات الصفحات التي يولدها السكربت. الحالات `pending`, `reviewed`, `unclear`؛
ليست الصفحة `reviewed` إذا بقي فيها محتوى تعليمي غير مفهوم. صفحـة خالية أو غلاف يمكن
تمييزها في `notes` بعد فتحها. لا تغيّر بصمة المصدر يدويًا.

```powershell
python "<skill-dir>/scripts/verify_pdf_review.py" --manifest "<absolute-path>/pdf-reading/manifest.json" --review "<absolute-path>/pdf-reading/review-log.json"
```

يتطلب الفحص صورًا موجودة وسجل `reviewed` لكل صفحة، ويكشف الصفحات الغائبة والغير
مقروءة وتضارب المصدر. عند طلب المستخدم نطاقًا معينًا، استخدم `--pages "٢٠-٣٠"` في
التحضير والتحقق؛ لا يشترط قراءة خارج نطاقه. لدرس داخل كتاب كامل، افحص جميع صفحات
ذلك الدرس بعد أن حددت حدوده، ثم تتبع بقية الدروس حتى اكتمال النطاق المطلوب.
هذا الفحص يراجع السجل والتغطية، ولا يستطيع إثبات أن الوكيل قرأ الصورة أو فهمها.

احفظ التفريغ المصحح بمؤشرات صفحات لتسهيل مقابلة الشمول، وسجّل تصحيح خطأ نقل دليل
في `editorial_notes` بذكر صفحة PDF والصفحة المطبوعة إذا عُرفت. بعد القراءة اتبع مسار
الصياغة والخرائط والتوثيق وبناء Word المعتاد.
