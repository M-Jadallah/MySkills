# المراجعة والاستئناف
راجع المصدر كاملًا: المسائل والأدلة والأمثلة والنفي والقيود والاستثناءات ونسبة الأقوال، ثم راجع التشكيل في سياقه مستقلاً. روابط المصدر لا تثبت حفظ المعنى. لا تختصر المصدر لتوفير التوكنز.
عند التصحيح استخدم inspect للسياق والمصدر والبصمة، وapply لتعديلات المقاطع المتوافقة. سجل review للفقرات المراجعة فقط أو --all بعد مراجعة الجميع فعلًا. status يبين المتبقي. اعتماد الشكل وحده لا يعتمد المحتوى.
تتبع البصمة نص الفقرة ووحدات مصدرها وعناوين قسمها وجوارها وعلاقات dependsOn المباشرة في الاتجاهين. تغيير النص أو الروابط يبطل الاعتمادات المتأثرة وترابط الدرس والعرض؛ الشكل وحده يبطل العرض. تغيير ملاحظة يبطل مراجعة الملاحظة والعرض. بعد أي تعديل أعد build قبل review.
coherence مراجعة مستقلة لتسلسل الدرس وحدود المقاطع ونهايته، وتجدد بعد تغيير نصي أو بنيوي. visual فحص الصفحات النهائية كاملة. تبقى الحالات generated_pending_reviews حتى اكتمال هذه المراجعات؛ الالتباس بحد ذاته لا يوقف التحرير أو التسليم، بل يكون complete_with_notes بعد المراجعات.
تحذيرات التشكيل اقتراح فحص وليست حكمًا؛ استخدم warning لحفظ قرار موثق للكلمة في سياقها. لا تعمم قرارًا بين السياقات، ولا تنشئ تعليقًا لكل تنبيه آلي. الالتباس الحقيقي يُحفظ لفظه ويوثّق بتعليق بنفسجي ثم تتابع المعالجة. check يعرض المفتوح فقط؛ التقرير التفصيلي والسجل يحتفظان بالقرارات السابقة. تغير النص أو سياقه يغير هوية التحذير.
ملف الحالة يحفظ تاريخ الاعتمادات المُبطلة. مصدر جديد يطابق الوحدات المطابقة بثقة فقط؛ راجع الروابط للمتغير. إذا كانت العلاقة العلمية تتجاوز الجوار، صرّح بها في dependsOn أو وسّع المراجعة يدويًا؛ البصمة ليست بديلًا عن الحكم العلمي.
