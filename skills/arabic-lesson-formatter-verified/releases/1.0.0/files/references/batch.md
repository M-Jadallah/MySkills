# الدفعات والاستئناف
للملفات المتعددة شغل وكيلًا فرعيًا لكل ملف بالتوالي وانتظر انتهاءه قبل التالي. مرر مسار المصدر والمهارة والمخرج والقيود اللازمة دون سجل كامل إذا أمكن. إن تعذر التفويض عالجها بنفسك بالتوالي. لا توقف الدفعة لفشل ملف.
node cli.js batch jobs.json report.json؛ jobs مصفوفة {lesson,source,output} بمسارات مطلقة. هذه أداة توليد للبيانات المحررة وليست بديلًا عن التحرير. تحفظ التقرير بعد كل ملف وتستأنف المخرج المطابق. مصدر متغير يعيد مطابقة وحداته ويحفظ اعتماد الأجزاء التي ثبت عدم تأثرها؛ تعديل نص يبطل مراجعة الفقرة وجوارها؛ الشكل وحده يبطل العرض. تحفظ حالة التوليد بجوار المخرج؛ لا تحذف وسيط المحتوى.
عند القفل تحفظ نسخة باسم لاحق. الفشل التقني لا يسجل نجاحًا. استئناف الإنتاج اللغوي يعتمد على الملفات الوسيطة المحفوظة؛ لا يعيد السكربت كتابة محتواها.

الحالة generated_pending_reviews لا تعني فشل التحرير؛ status يحدد المراجعات الباقية. لا تغير ملف الحالة يدويًا لإعلان complete.
