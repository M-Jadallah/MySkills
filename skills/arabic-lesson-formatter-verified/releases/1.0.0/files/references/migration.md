# الترحيل إلى الإصدار ٤
node cli.js migrate old.json source.json new.json
يحفظ النص والتعليقات وروابط المصدر والمعرفات السليمة؛ يرفض الاختلاف بين text وruns والتكرارات بدل إصلاحها تخمينيًا. يولد معرفات الناقص فقط وعدّادات متزايدة وسجل المعرفات المحذوفة.
احتفظ بالنسخة القديمة قبل الترحيل. rebuild يحتفظ باعتمادات الإصدار السابق في history فقط؛ لا تعد بصماتها مراجعات حديثة. راجع المصدر والناتج وسجل الاعتمادات الجديدة. شغّل check بعد الترحيل. لا ترحّل بتبديل رقم version يدويًا.
