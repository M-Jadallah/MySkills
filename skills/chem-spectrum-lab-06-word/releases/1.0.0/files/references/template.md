# هيكل ملف Word المطلوب — الدرس [الرقم]

## التدرج (من الكلي إلى الجزئي)
```
الغلاف → خريطة الدرس → الأهداف+المفاهيم → المحتوى النظري → المعادلات
→ الجداول → التجارب العملية → الأمثلة المحلولة → الخلاصة → التمارين
→ قاموس المصطلحات → روابط+تواصل
```

## 1. الغلاف
شعار + "الدرس [الرقم]: [العنوان]" + "الصف: التوجيهي - الأردن" + المدرس + التواصل + "الفهم قبل الحفظ".

## 2. خريطة الدرس (Mind Map)
رسم بسيط يربط المفاهيم ويوضح "أين نحن".

## 3. الأهداف + المفاهيم الأساسية
نقاط الأهداف + تعريف المفاهيم.

## 4. المحتوى النظري
إطار خفيف لكل فقرة: عنوان فرعي (كبير/لون) → نقاط رئيسية → تفاصيل → صندوق ملاحظة جانبي.

## 5. المعادلات
صندوق لكل معادلة: الاسم + `$$...$$` (PNG) + الشرح + ⚠️ ملاحظة.

## 6. الجداول
رأس كحلي + نص أبيض؛ صفوف متناوبة أبيض/رمادي.

## 7. التجارب العملية
صندوق: الهدف | المواد | الخطوات | الملاحظات | الاستنتاج.

## 8. الأمثلة المحلولة
صندوق: المسألة | الحل (خطوة بخطوة) | ✅ الإجابة النهائية.

## 9. الخلاصة (نقاط ذهبية)
5–7 نقاط يجب تذكرها + صندوق ذهبي فاتح.

## 10. التمارين
أسئلة + **مساحة فارغة للحل** + تلميح في الهامش.

## 11. قاموس المصطلحات
جدول: المصطلح | التعريف.

## 12. روابط + تواصل
رابط المختبر + أرقام التواصل.

## الرأس والتذييل (كل صفحة)
- الرأس: اسم الدرس + "مختبر الطيف للكيمياء"
- التذييل: رقم الصفحة + "م. معتصم جادالله"

## مبدأ التدرج (من البسيط إلى المعقد)
مقدمة (لماذا؟) → مفهوم أساسي (ماذا؟) → تفاصيل (شرح كامل) → تطبيق (أمثلة/تجارب) → تعمق (قوانين/معادلات) → تقييم ذاتي (تمارين).
