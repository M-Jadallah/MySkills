# قالب مكونات المختبر المنفصل — الدرس [الرقم]

هذا القالب يصف المكونات الإلزامية لكل درس. السكافولد (`scripts/scaffold.py`) يولّد هيكلها؛ املأ التفاصيل من `design-XX.md`.

## هيكل المجلد
```
frontend/lessons/lesson-XX/
├── index.html              ← الصفحة الرئيسية
├── css/
│   └── lab-style.css       ← أنماط الدرس (متغيرات الهوية في :root)
├── js/
│   ├── experiment.js       ← منطق التجربة التفاعلية
│   ├── molecules.js        ← الرسوم الجزيئية على Canvas 2D
│   └── charts.js           ← الرسوم البيانية (Chart.js خفيف)
└── assets/
    └── [صور خاصة بالدرس + logo.png / logo-dark.png]
```

## 1. شاشة البداية (Start Screen)
- شعار "مختبر الطيف"
- عنوان الدرس
- اسم المدرس (م. معتصم جادالله)
- زر "ابدأ التجربة"
- أرقام التواصل (📞 0788521514 — 💬 +962 78 852 1514)

## 2. منطقة العمل الرئيسية (Workspace)
- خلفية طاولة مختبر واقعية
- الأدوات: دورق، أنابيب اختبار، موقد، ميزان (SVG قابلة للسحب/الضغط)
- تفاعل: سحب وإفلات / ضغط / تمرير (mouse + touch)

## 3. صندوق الشرح المختصر (Brief Box)
- 2–3 سطور فقط
- قابل للإخفاء والإظهار
- يظهر عند الحاجة / بعد الفعل

## 4. لوحة التحكم (Control Panel)
- إعادة التجربة (reset)
- تلميح (hint)
- إظهار المعادلة (show equation — بصيغة LaTeX المقدمة من الدرس)
- تغيير المتغيرات (change variables)

## 5. شاشة الإنجاز (Completion)
- رسالة نجاح
- نقاط
- زر "الدرس التالي"
- زر "قائمة الدروس"

## التقنيات المعتمدة
HTML5 · CSS3 (+ animations) · JavaScript Vanilla · Canvas 2D · SVG · Chart.js (خفيف)

## ❌ ممنوع (لأداء الجوال)
Three.js / WebGL معقد · فيديوهات ثقيلة · React/Vue/Angular · مكتبات ضخمة

## التوافق: حاسوب vs هاتف
| العنصر | الحاسوب | الهاتف |
|--------|---------|--------|
| التخطيط | عمل + أدوات + شرح جنباً | عمل أعلى، أدوات شريط سفلي |
| التفاعل | ماوس دقيق + hover | لمس مُحسّن، أزرار أكبر |
| الأدوات | جانبية | شريط سفلي قابل للسحب |
| الشرح | صندوق جانبي | نافذة منبثقة |
