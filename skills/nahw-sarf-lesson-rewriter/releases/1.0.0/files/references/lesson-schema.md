# مخطط lesson.json (JSON Schema Reference)

اكتب ملف JSON الوسيط بهذا الشكل الحرفي بالضبط، ثم تحقق بـ `python scripts/validate_input.py --input lesson.json` وابنِ بـ `python scripts/build_docx.py --input lesson.json --output lessons_output/<اسم>.docx`.

## الحقول الجذرية

| الحقل | النوع | إلزامي | ملاحظات |
|---|---|---|---|
| `title` | نص | نعم | **رقم الدرس مع الموضوع فقط**، مشكول بالكامل بأرقام عربية (مثل «١٢ - الْمَمْنُوعُ مِنَ الصَّرْفِ»)؛ يُعرض Heading 1 أحمر مركزيًا |
| `subtitle` | نص | لا | سطر تعريفي بني تحت العنوان (مثل «شَرْحُ أَلْفِيَّةِ ابْنِ مَالِكٍ») |
| `sections` | قائمة | نعم | محاور الدرس بترتيبها، غير فارغة |

## الحقول داخل كل محور (section)

| الحقل | النوع | إلزامي | ملاحظات |
|---|---|---|---|
| `heading` | نص | نعم | عنوان المحور، يُعرض Heading 2 أحمر قابل للطي |
| `blocks` | قائمة | لا (الافتراضي `[]`) | محتوى المحور — أنواعها أدناه |
| `subsections` | قائمة | لا (الافتراضي `[]`) | نفس بنية المحور: `heading` + `level` (عدد صحيح ≥ 2) + `blocks` + `table` + `concept_map` + `subsections` متداخلة |
| `section_summary` | نص | لا | **تجنّبه عادة** — المستند كله صياغة مختصرة أصلًا؛ إن استُخدم يظهر بعنوان "◆ خُلَاصَةُ القِسْمِ" |
| `table` | كائن | لا | `{title, headers, rows}` — عند الحاجة فقط (قواعده في rewriting-rules.md §4) |
| `concept_map` | كائن | لا | `{label, children}` — **قدر الإمكان** (قواعده في rewriting-rules.md §5)؛ تُدرج بلا أي عنوان فوقها |

## أنواع البلوكات (blocks)

| النوع | الحقول | الوصف |
|---|---|---|
| `paragraph` | `text` | فكرة/مسألة كاملة بصياغتك، مشكولة؛ افصل الأفكار المستقلة في بلوكات متعاقبة |
| `evidence` | `text` | **بيت من ألفية ابن مالك فقط** بشطريه مفصولين بـ «…» بنصه الصحيح المضبوط — يُعرض مركزيًا بخط أخضر غامق عريض على تظليل أخضر فاتح تلقائيًا؛ لا تضف زخارف ولا مقدمة ولا تنصيص |
| `bullet_list` | `items` | عناصر متوازية لا يهم ترتيبها (`•` تلقائي؛ لا تكتبه داخل العنصر) |
| `numbered_list` | `items` | خطوات أو مسائل يهم ترتيبها (`١.` `٢.`... تلقائي؛ لا تكتب الأرقام داخل العناصر) |

## المثال الحرفي الكامل

```json
{
  "title": "١ - الْمُقَدِّمَةُ: حَقِيقَةُ الْكَلَامِ وَأَقْسَامُهُ",
  "subtitle": "شَرْحُ أَلْفِيَّةِ ابْنِ مَالِكٍ",
  "sections": [
    {
      "heading": "تَعْرِيفٌ بِمُؤَلِّفِ الْأَلْفِيَّةِ وَمَنْظُومِهَا",
      "blocks": [
        {"type": "paragraph", "text": "نَظَمَ الْمُؤَلِّفُ أَلْفِيَّتَهُ لِتَيْسِيرِ حِفْظِ قَوَاعِدِ النَّحْوِ وَالصَّرْفِ، وَفَاتَحَهَا بِبَيْتٍ يَتَنَاسَبُ مَعَ مَا تَحْتَاجُهُ الْقَصِيدَةُ مِنْ تَعْرِيفٍ بِمُنْظِمِهَا."},
        {"type": "evidence", "text": "قَالَ مُحَمَّدٌ هُوَ ابْنُ مَالِكٍ … أَحْمَدُ رَبِّيَ اللَّهُ خَيْرُ مَالِكِ"}
      ],
      "subsections": [],
      "concept_map": {
        "label": "أَلْفِيَّةُ ابْنِ مَالِكٍ",
        "children": ["مُنْظَمَةٌ عَلَى الرَّجَزِ", "فِي النَّحْوِ وَالصَّرْفِ", "غَايَتُهَا تَيْسِيرُ الْحِفْظِ"]
      }
    },
    {
      "heading": "حَقِيقَةُ الْكَلَامِ وَشُرُوطُهُ",
      "blocks": [
        {"type": "paragraph", "text": "الْكَلَامُ لَفْظٌ مُفِيدٌ مُسْتَقِيمُ الْبِنَاءِ لَا يَقَعُ فِي غَيْرِ مَوْضِعِهِ، وَيَنْقَسِمُ إِلَى اسْمٍ وَفِعْلٍ وَحَرْفٍ."},
        {"type": "evidence", "text": "كَلَامُنَا لَفْظٌ مُفِيدٌ كَاسْتَقَامَ … وَاسْمٌ وَفِعْلٌ ثُمَّ حَرْفُ الْكَلِمِ"}
      ],
      "subsections": [
        {
          "heading": "شُرُوطُ الْكَلَامِ الثَّلَاثَةُ",
          "level": 2,
          "blocks": [
            {"type": "bullet_list", "items": ["لَفْظٌ: مَا يَتَأَلَّفُ مِنْ أَحْرُفِ الْمَدِيحِ.", "مُفِيدٌ: يَفِيدُ فَائِدَةً تَقْتَضِيهَا حَاجَةُ السَّامِعِ فَتُسْكِتُهُ.", "كَاسْتَقَامَ: مُسْتَقِيمُ الْبِنَاءِ لَا يَقَعُ فِي غَيْرِ مَوْضِعِهِ."]}
          ],
          "subsections": [],
          "concept_map": {
            "label": "شُرُوطُ الْكَلَامِ",
            "children": ["لَفْظٌ", "مُفِيدٌ", "مُسْتَقِيمُ الْبِنَاءِ"]
          }
        }
      ]
    },
    {
      "heading": "أَقْسَامُ الْكَلَامِ وَالْفَرْقُ بَيْنَ الْكَلِمَةِ وَالْقَوْلِ",
      "blocks": [
        {"type": "paragraph", "text": "قَسَمَ الشَّاعِرُ الْكَلَامَ إِلَى ثَلَاثَةِ أَقْسَامَ: الِاسْمُ وَالْفِعْلُ وَالْحَرْفُ، وَبَيَّنَ أَنَّ الْكَلِمَةَ قَوْلًا مُنْفَرِدًا."},
        {"type": "evidence", "text": "وَاحِدُهُ كَلِمَةٌ وَالْقَوْلُ عَمٌّ … وَكَلِمَةٌ بِهَا كَلَامٌ قَدْ يُؤَمُّ"}
      ],
      "subsections": [],
      "table": {
        "title": "أَقْسَامُ الْكَلَامِ",
        "headers": ["الْقِسْمُ", "مِثَالٌ"],
        "rows": [
          ["الِاسْمُ", "زَيْدٌ"],
          ["الْفِعْلُ", "فَهِمَ"],
          ["الْحَرْفُ", "مِنْ"]
        ]
      },
      "concept_map": {
        "label": "أَقْسَامُ الْكَلَامِ",
        "children": ["الِاسْمُ", "الْفِعْلُ", "الْحَرْفُ"]
      }
    }
  ]

```

## تنبيهات سريعة

1. كل النصوص مشكولة تشكيلًا كاملًا وﷺ وأرقام عربية.
2. `title` = رقم الدرس مع الموضوع فقط؛ وعناوين المحاور من مضمون التفريغ.
3. كل بيت في بلوك `evidence` بشطريه مفصولين بـ «…»، بنصه الصحيح المضبوط، بلا مقدمة ولا تنصيص.
4. لا تكرّر نص الصياغة حرفيًا داخل الجدول أو الخريطة، ولا تتخطَّ ترتيب الورود.
5. عدد الخلايا في كل `rows[i]` = عدد `headers` بالضبط.
6. عنوان عقدة الخريطة ≤ ١٦٠ حرفًا، وعمق التداخل ≤ ٦.
7. لا نص تمهيدي فوق الخريطة — المحرك يدرجها بعد المحتوى مباشرة.
8. بعد الكتابة: `validate_input.py` ثم `build_docx.py` — بوابة التسليم في SKILL.md.
