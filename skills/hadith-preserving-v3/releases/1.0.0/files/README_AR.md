# منسّق الأحاديث الحرفي v1.1.2

حزمة لتحويل ملف TXT واحد أو عدة ملفات TXT مرقمة إلى ملف Word عربي واحد، مع حذف الحواشي وأرقام الصفحات والمحافظة الحرفية على الأحاديث والحركات.

## أهم خصائص الإصدار

- ملف Word بلا جداول؛ كل حديث فقرة عادية قابلة للتعديل والنقل.
- صندوق أخضر لعناوين الكتب والأبواب مع حدود سوداء كاملة.
- تلوين سلسلة الرواة كاملة باللون الخمري، لا اسمًا واحدًا فقط.
- تلوين جميع متون الروايات داخل `« »` بالبني الغامق وجعلها Bold فعليًا في العربية.
- جعل سطر المعنى كاملًا Bold، لا المصطلح وحده.
- كتابة علامتي التغميق `w:b` و`w:bCs` مع تدقيق بنيوي يمنع التسليم إذا لم يثبت Bold العربي.
- استخدام Semantic Maps ينشئها الوكيل بالذكاء الاصطناعي لتصنيف المتون والمعاني الملتبسة، مع تحقق exact-anchor يمنع تغيير النص.
- قياس كل حديث على صفحة فارغة كاملة؛ يبقى 24 إن اتسع، وإلا يُختار أكبر حجم صالح بدقة نصف نقطة.
- تقسيم صارم إلى أجزاء من 20 صفحة، والجزء الأخير فقط قد يكون أقصر.
- معالجة عدة كتب في عمال متوازية ثم دمجها بترتيب أرقام الملفات.
- دورة إصلاح تلقائية قبل الدمج، دون إخراج ملف ناقص بصمت.

## المتطلبات

- Python 3.10 أو أحدث.
- LibreOffice أو `soffice` لقياس الصفحات الحقيقي.
- الحزم الموجودة في `requirements.txt`.
- وجود خط Traditional Arabic على الجهاز يعطي المظهر المرجعي الكامل.

```bash
pip install -r requirements.txt
python scripts/check_environment.py
```

## تسمية ملفات الإدخال المتعددة

يجب أن يبدأ كل اسم ملف برقم ترتيب فريد:

```text
01 - كتاب الطهارة.txt
02 - كتاب الصلاة.txt
03 - كتاب الزكاة.txt
```

## تشغيل ملف واحد

```bash
./run.sh input.txt output.docx
```

أو:

```bash
python scripts/format_hadith.py input.txt output.docx \
  --semantic-map input.semantic.json \
  --audit-json output.audit.json \
  --clean-txt output.clean.txt
```

## تشغيل مجلد كامل

```bash
./run.sh ./books output.docx --jobs 4
```

أو:

```bash
python scripts/format_hadith_batch.py ./books output.docx \
  --semantic-dir ./semantic-maps \
  --jobs 4 \
  --intermediate-dir ./worker-results \
  --audit-json output.audit.json \
  --clean-txt output.clean.txt
```

## منطق المعالجة المتعددة

1. اكتشاف ملفات TXT المرقمة.
2. ترتيبها تصاعديًا حسب الرقم.
3. معالجة كل كتاب في عامل معزول.
4. حذف الحواشي والتحقق من النص وإعادة المحاولة تلقائيًا عند وجود مشكلة قابلة للإصلاح.
5. حفظ مخرجات وسيطة لكل كتاب.
6. رفض الدمج الناقص؛ لا يُسقط أي كتاب بصمت.
7. دمج الوحدات النصية بالترتيب.
8. قياس كل حديث على صفحة كاملة، وعدم تصغيره بسبب فراغ الصفحة السابقة، ثم اختيار أكبر حجم صالح عند الضرورة.
9. إنشاء Word واحد ثم ضبط الأجزاء عالميًا كل 20 صفحة.
10. إنشاء تقرير تدقيق نهائي.

## قواعد النص

لا تتغير الحروف أو الحركات أو أسماء الرواة أو عبارات الترضي. الاستبدال الوحيد داخل النص هو:

```text
صلى الله عليه وسلم  →  ﷺ
```

## تنسيق المستند

- Traditional Arabic.
- حجم افتراضي 24 نقطة.
- اتجاه RTL.
- السند أسود.
- سلسلة الرواة خمرية.
- المتون كلها بنية غامقة وBold بعلامتي `w:b` و`w:bCs`.
- المعاني كلها سوداء وBold كسطر كامل.
- عناوين الكتب والأبواب خضراء بحد أسود.
- رقم الصفحة في المنتصف.
- لا يحتوي متن المستند على أي جدول.
