# عقد الإدخال

كائن JSON: `title` عنوان عام مشكول؛ أو `bookTitle` و`lessonTitle` لدمجهما. `paragraphs` مصفوفة مرتبة غير فارغة.

كل فقرة: `type` أحد heading1، heading2، paragraph، bullet، summary، closing؛ و`text` كامل مشكول. `level` يساوي 0 للرئيسية و1 للتابعة، إلزامي لكل متن تحت heading1 أو heading2 ولكل bullet. لا level للعناوين والخاتمة. بداية عنوان جديد تقطع علاقة التبعية؛ لا يبدأ قسم بفرعية دون رئيسية.

`runs` اختياري: مصفوفة كائنات `{text, bold?, color?, shading?}`. يجب أن يساوي لصق نصوصها text حرفيًا قبل التطبيع. bold قيمة منطقية؛ color إن وجد EE0000، وshading إن وجد D9F2D0. النص العادي يكتفي بـtext. لا تكتب علامات القوائم في text؛ يمكن إدراج رقم الترتيب فيه. summary عريض كله.

التطبيع آلي للأرقام الغربية إلى المشرقية وm/M إلى م. لا تُستخدم التجزئة إلى runs لإسقاط نص. لا يُشكّل السكربت النص؛ ذلك مسؤولية الوكيل. فحص الكلمات غير المشكولة لا يثبت صحة الإعراب ولا اكتمال الحركات.

المستوى الرئيسي: إزاحة يمين 360 twips وتعليق 240. التابع: يمين 720 وتعليق 240. الشرطة والدائرة من numbering.xml، وليستا جزءًا من النص. ينبغي فحص العرض في Word خصوصًا للأسطر الطويلة.

علامتا المستويين بالأحمر C00000، مستقلتين عن لون نص الفقرة.
