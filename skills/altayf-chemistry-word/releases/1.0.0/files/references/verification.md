# التحقق والتسليم

## بوابات الاكتمال

1. **المصدر**: بصمته لم تتغير، كل عنصر علمي مفهرس ومقروء، ولا علامة استخراج غير معالجة.
2. **التغطية**: كل حقيقة وشرط واستثناء ومعلومة رسم موجودة في الدرس الكامل وإعادة الصياغة، وممثلة بإيجاز في المكثف. كل استبعاد له سبب غير علمي واضح. راجع المعنى، لا الكلمات والأرقام وحدها.
3. **الأسئلة**: الأصلية محفوظة، والجديدة داخل النطاق ومناسبة لموضعها، والصعوبة متنوعة دون تكرار، ولكل اختيار متعدد إجابة صحيحة واحدة، وجميع الفروع والمعطيات مكتملة.
4. **المعلم**: عدد الأسئلة ومعرفاتها وترتيبها ونصوصها تطابق الطالب، والخطوات والإجابات والوحدات صحيحة ومفحوصة استقلالًا.
5. **الهوية**: الخلفية والشرائط المعتمدة، وشارة رقم الوحدة بجوار اسم الدرس، والخط والمقاسات، وكل المربعات بشفافية94%، وصور بلا إطار معتم، وقوانين ورموز منظمة، ومفردات عربية في بطاقات مستقلة.
6. **البنية**: معادلات قابلة للتحرير، وأرقام صفحات صحيحة، ولا علاقة أو صورة مفقودة، ولا خلية معتمة أو ارتفاع ثابت يقص النص، وتعداد واتجاهات سليمة.
7. **المظهر النهائي**: كل صفحة من كل ملف صُيّرت وفُحصت؛ لا تداخل أو قص أو رمز مفقود أو جدول منفصل بلا سبب، ولا فراغات ضخمة بسبب سلسلة keepNext طويلة. افحص أمثلة ومعادلات «المسألة/المعطيات/الخطوات/الإجابة»، ومربع جواب التدريب والتمرين، وخط الجدول10.5، والتعريف13، والغامق داخل النص والخلايا، وشكل المفردات والملخص، ووجود «تذكّر عند الحل» في النهاية. تحقّق خصوصًا من أن الشريط **ظاهر فعليًا** في الصفحة؛ وجود صورته داخل DOCX وحده لا يكفي، فقد يقطعها ارتفاع السطر.

## تشغيل الأدوات

استبدل `PYTHON` بالرنتايم المكتشف، و`SKILL` بمسار المهارة، و`RUN` بمجلد عمل جديد. لا تنسخ مسارات الجهاز الأصلي.

```text
PYTHON SKILL/scripts/preflight.py
PYTHON SKILL/scripts/audit_package.py --assets --report RUN/qa/assets.json
PYTHON SKILL/scripts/source_inventory.py SOURCE.docx RUN/source
PYTHON SKILL/scripts/validate_plan.py RUN/lesson-plan.json --report RUN/qa/plan.json
PYTHON SKILL/scripts/build_documents.py RUN/lesson-plan.json RUN
```

إذا تطلبت مهارة documents المتاحة علامة بدء التأليف، شغّلها مرة واحدة حسب تعليماتها قبل أول تأليف DOCX. لا تنسخ أدوات الرنتايم الخاصة بها إلى هذه الحزمة، ولا تكرر العلامة لكل إصلاح.

الكاتب يأتي بعد نجاح فحص الخطة. افحص المخرجات نفسها؛ صحة الخطة لا تثبت سلامة تطبيقها.

## تسلسل Word والشفافية

يمكن تشغيل السلسلة كاملة بالتتابع عبر `PYTHON SKILL/scripts/finish_documents.py RUN/output-manifest.json NEW_QA_DIR`. هذا يحفظ البصمات وأعداد الصفحات بعد آخر تصدير، لكنه يترك الموافقة البصرية `pending` حتى يراجع الوكيل كل الصور. إذا توقف عند مربع منقسم، أصلح التدفق أولًا واستعمل مجلد QA جديدًا. أو نفّذ الخطوات أدناه يدويًا.

على Windows مع Word، شغّل `word_layout.ps1` على نسخ الناتج فقط. لا تعدّل أو تصدّر الملف ذاته في عمليتين متوازيتين. أكمل وأغلق كل خطوة قبل التالية. لا تستخدم `Stop-Process WINWORD`، ولا تحذف أقفال ملفات المستخدم.

استعمل PowerShell7 الموجود في الرنتايم (`pwsh`) عند توفره؛ هو المسار الذي اجتاز اختبار التصدير على جهاز المرجع. لوحظ تعليق في Windows PowerShell5 على الحزمة نفسها بينما نجح PowerShell7. لا تغيّر البرنامج إلى Windows PowerShell لمجرد أنه ضمن System32. السكربت المجمع يفضّل `pwsh` ويستعمل البديل عند غيابه؛ إذا علق البديل، شخّصه أو استعمل المصيّر المتاح، ولا تكرر الانتظار بلا دليل تقدم. يحفظ السكربت صراحة ثم يعيد فتح الملف المحفوظ للقراءة قبل تصدير PDF.

لكل ملف، بالتسلسل:

```powershell
& "$skillPath/scripts/word_layout.ps1" -Mode export -DocumentPath $docPath -OutputDirectory $initialChunks
```

بعد انتهاء مثيل Word وإغلاقه:

```text
PYTHON SKILL/scripts/render_pages.py INITIAL_CHUNKS INITIAL_RENDER
PYTHON SKILL/scripts/card_geometry.py DOCX INITIAL_RENDER/document.pdf CARDS.json BOUNDS.json
```

ثم:

```powershell
& "$skillPath/scripts/word_layout.ps1" -Mode tint -DocumentPath $docPath -BoundsPath $boundsPath
& "$skillPath/scripts/word_layout.ps1" -Mode export -DocumentPath $docPath -OutputDirectory $finalChunks
```

ثم:

```text
PYTHON SKILL/scripts/render_pages.py FINAL_CHUNKS FINAL_RENDER
PYTHON SKILL/scripts/verify_ribbon_visibility.py FINAL_RENDER/document.pdf FINAL_RENDER CARDS.json --report RIBBON_REPORT.json
PYTHON SKILL/scripts/audit_package.py --docx DOCX --cards CARDS.json --final --report REPORT.json
```

كل تصدير إلى مجلد جديد؛ بقايا PDF قد تكرر الصفحات. المسار الافتراضي يحفظ DOCX ثم يصدر PDF أصليًا عبر Word SaveAs2، ويغلق نسخة PDF دون حفظ إضافي على المصدر. هذا تجنّب تعليقًا لوحظ في ExportAsFixedFormat على القالب. يمكن استعمال `-ExportMethod chunks` للتصدير من10 صفحات إذا ثبت عمله على الجهاز؛ لا تعِد مسارًا عالقًا مرارًا. الدمج يقبل PDF كاملًا أو أجزاء متصلة ويرفض الفجوات والتداخل. يقيس سكربت المربعات ألوان حدود مؤقتة فريدة في PDF، ثم يعيد الحدود المعتمدة إلى DOCX قبل التعبئة. لا تسلم الحدود المؤقتة.

التعبئة شكل خلف النص مقاسه من التصيير، وليست `w:shd`. يتحقق Word من أن مرساة العلامة على الصفحة المقصودة. إذا انقسم مربع على عدة صفحات، يرفضه القياس الافتراضي: عدّل التدفق أو قسّمه بوعي إلى أجزاء ذات مراسٍ خاصة، ثم أعد التصيير. لا تُرسِ خلفيات جميع صفحات جدول طويل إلى الصفحة الأولى. افحص عدم انجراف المواقع بعد التعبئة.

إذا كان الناتج مفتوحًا أو للقراءة فقط، استخدم اسم إخراج جديدًا وأعد المحاولة مرة واحدة. لا تكرر المحاولة دون حد ولا تنه عمليات المستخدم. يضمن `finally` إغلاق مستند الأداة ومثيلها وحدهما. لا تترك جلسة تصدير عالقة ثم تبدأ تعديل الملف.

## البديل والقيود

عند تعذر Word، اكتشف renderer الخاص بمهارة documents أو LibreOffice المثبت. لا تفترض أن البرامج غائبة على كل جهاز. حافظ على علاقات الرأس والتذييل وافحص اختلافات التوافق. لقطة HTML ليست تصيير Word.

لشفافية OOXML استخدم DrawingML خلف النص مع `a:alpha6000` ومرساة صحيحة، واختبره في المصيّر المتاح. لا تستبدله بتظليل معتم. عند تعذر التصيير أو إثبات الشفافية، احفظ العمل واذكر التحقق المتبقي؛ لا تصف الناتج بأنه نهائي مفحوص اعتمادًا على ZIP أو صفحة واحدة.

## دليل المراجعة البصرية

أنشئ `qa/visual-review.json`: اسم كل ملف، بصمته بعد آخر حفظ، عدد الصفحات، وحالة **كل صفحة** مع الإصلاحات. يمكن استعمال contact sheet للفرز، ثم افتح النص والمعادلات والجداول بدقة تسمح بقراءة الحروف.

افحص أول وآخر صفحة، وجميع القوانين والأسس والكسور والمؤشرات والرموز والوحدات، والأقواس العربية واللاتينية والأعداد العشرية. افحص كل الأمثلة والتمارين: لا عنوان نوع مكرر، لا حل متسرب، وكل شريط مرقم وصحيح. افحص استمرار القوائم والرسوم والمفردات. في المعلم تحقق من ظهور السؤال والحل والوحدة كاملة. اربط محدد السؤال بالبطاقة التالية عبر keep-with-next؛ لا تترك عنوان الموضع وحيدًا في أسفل صفحة بينما السؤال في الصفحة التالية.

قارن صفحات ممثلة من **كل ملف** مع صور `assets/reference-pages/example-layout.png`, `training-layout.png`, `law-symbols.png`, `arabic-glossary.png`. ارجع إلى لقطة بدقة عالية لكل صفحة عند فحص نصوص المعادلات والغامق في خلايا الجدول؛ صورة الاتصال المصغّرة تكشف التدفق فقط. تحقّق من أن خلية الجدول تعرض النص العلمي نفسه، لا تمثيل JSON مثل `{'text': ...}`. افحص شارة الوحدة مرئيًا على أول الصفحة وبقية الصفحات، واترك فراغًا واضحًا بينها وبين العنوان والشعار. ربط `audit_package.py` يتحقق من البنية وبعض أحجام الخط، لكنه لا يغني عن مقارنة العين.

أي إصلاح يؤثر في التفاف النص يستلزم إعادة القياس والتعبئة والتصدير. راجع الصفحات المتأثرة والانجراف في الصفحات التالية. بعد اجتياز المخاطر الفعلية، أكمل التسليم دون إضافة اختبارات اختيارية لا حاجة لها.

## ماذا تثبت الفحوص الآلية؟

`validate_plan.py` يفحص التصنيف ومعرفات التغطية والحلول وحسابات صريحة وبعض مشكلات الاختيار المتعدد والمفردات. لا يثبت صدق كل ربط دلالي. `audit_package.py` يفحص الأصول والخلفية والشفافية والجداول والهندسة، لكنه لا يفهم العلم في الرسم. `render_pages.py` ينتج كل صور الصفحات ويفحص خروج النص عن الصفحة؛ لا يمنح نجاحًا بصريًا تلقائيًا.

قبل التسليم حدّث بصمات `output-manifest.json` بعد آخر حفظ، وسجل الصفحات والأسئلة والصور الفعلية. سلّم روابط الملفات المطلوبة فقط، مع قيد حقيقي إن وجد. سجلات QA والتصيير داخلية إلا إذا طُلبت. لا تضف ملف دوسية سادسًا تلقائيًا.
