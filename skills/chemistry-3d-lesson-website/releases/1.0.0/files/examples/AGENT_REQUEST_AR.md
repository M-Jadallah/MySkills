# مثال طلب جاهز للوكيل

استخدم مهارة `chemistry-3d-lesson-website` لتنفيذ المهمة كاملة على ملف الدرس المرفق.

الملفات المرفقة هي:

1. ملف الدرس الجديد: المصدر العلمي والتعليمي.
2. المشروع المرجعي الأخير: المرجع المعتمد للتصميم والتفاعل وسطح المكتب والهاتف والخاتمة.
3. ملف HTML المستقل الأخير: المرجع النهائي للسلوك والعمل دون الإنترنت.
4. أصول الهوية: الشعارات والصور المعتمدة.

نفّذ التحليل، ثم التصميم، ثم البرمجة، ثم الاختبارات العلمية والوظيفية والبصرية، ثم أصلح كل الأخطاء وأعد الاختبارات. لا تسلّم أول نسخة تعمل. لا تغيّر هوية «الطيف في الكيمياء» ولا الخاتمة المعتمدة.
