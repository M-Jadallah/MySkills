# Delivery Contract

## Required project outputs

- source-code folder;
- offline standalone HTML;
- complete ZIP archive;
- Arabic README;
- content map;
- interaction map;
- source-correction report;
- scientific validation report;
- functional test report;
- responsive test report;
- accessibility report;
- performance report;
- code-quality report;
- test logs;
- desktop screenshots;
- mobile screenshots;
- major simulation screenshots;
- final release-gate summary.

## Required final summary fields

- scientific tests: passed / total;
- unit-conversion tests: passed / total;
- invariant tests: passed / total;
- control tests: passed / total;
- end-to-end tests: passed / total;
- responsive tests: passed / total;
- accessibility checks: passed / total;
- code-quality status;
- offline standalone status;
- console error count;
- missing asset count;
- remaining limitations.

Use actual executed numbers only.

## Screenshot evidence

Desktop evidence should include hero, concept section, major simulation, worked example, assessment, and footer.

Mobile evidence should include hero, section navigation, collapsed simulation, expanded simulation, controls, assessment, and footer.
