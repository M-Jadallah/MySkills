## 9. ⚠️ الخطة 3D الإلزامية (خطة التنفيذ الواضحة)
*هذا القسم إلزامي. بدونه التقرير غير مكتمل. ضع خطة تنفيذ صريحة لكل مشهد 3D.*

### 9.1 جدول خطة المشاهد
| المشهد | مهارة/قدرة 3D مساندة | التأثير البصري | مستوى الجوال (tier) |
|--------|----------------------|----------------|---------------------|
| [الأسطوانة الزجاجية + الجزيئات] | [MeshTransmissionMaterial + threejs-bloom + Sparkles] | [توهّج سماوي، جزيئات مضيئة] | [epic: Bloom+Sparkles كاملة / lean: بلا Bloom، Sparkles قليلة] |
| [المكبس القابل للسحب] | [useFrame + raycasting من threejs-interaction] | [حركة سلسة، ارتداد] | [epic/lean: نفس المنطق] |
| [رسم بياني حي] | [Html من drei + خطوط] | [تحديث فوري] | [epic/lean] |
| ... | ... | ... | ... |

### 9.2 استراتيجية المستويات (Animation Tiers)
- **Epic (سطح المكتب، pointer:fine، عرض ≥1024):** كل التأثيرات — Bloom قوي، Sparkles ×120، جزيئات كاملة، ظلال.
- **Lean (جوال، باقي الحالات):** بلا Bloom، Sparkles ×35، جزيئات أقل، نفس المنطق التفاعلي.
- **الكشف:** `src/shared/device.ts` → `detectTier()` يحدد epic/lean عند التحميل.
