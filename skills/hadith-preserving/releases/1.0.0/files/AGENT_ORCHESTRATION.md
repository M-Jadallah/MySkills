# بروتوكول الوكلاء الفرعيين

## دور الوكيل الرئيسي

- اكتشاف ملفات TXT المرقمة وترتيبها.
- إنشاء وكيل فرعي لكل ملف.
- تمرير العقد النصي نفسه لكل وكيل.
- جمع تقارير السلامة، وإعادة الملفات المتعثرة إلى أصحابها مع وصف دقيق للخلل.
- عدم الدمج حتى تنجح جميع الكتب.
- دمج الوحدات النصية، وليس لصق ملفات Word منفصلة.
- إعادة بناء Word النهائي كاملًا بعد أي إصلاح لأن توزيع الصفحات قد يتغير.

## مخرجات الوكيل الفرعي

لكل كتاب:

- `cleaned.txt`
- `units.json`
- `worker-result.json`

يجب أن يتضمن التقرير بصمة المصدر، بصمة النص المنظف، عدد الأحاديث، سجل الإصلاحات، وحالة `PASS`.

## دورة التحسين الذاتي الآمنة

1. تحديد موضع الاختلاف أو العنصر المتبقي.
2. العودة إلى الملف الخام.
3. تعديل قاعدة الاكتشاف أو التجزئة فقط.
4. إعادة التنظيف والتحليل.
5. مقارنة المحارف غير البيضاء.
6. تكرار الدورة حتى النجاح.

ممنوع أن يكون الإصلاح بتخمين نص حديث، أو تصحيح الرواية، أو حذف عبارة مختلف عليها لإجبار الفحص على النجاح.
