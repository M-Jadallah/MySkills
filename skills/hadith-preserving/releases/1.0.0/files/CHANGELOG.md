# سجل التغييرات

## 1.1.1 — 2026-07-16

- إصلاح جذري لخوارزمية ملاءمة الحديث الطويل.
- منع تصغير الحديث بسبب المساحة المتبقية أسفل الصفحة السابقة.
- قياس كل حديث على صفحة فارغة كاملة قبل اتخاذ قرار التصغير.
- الإبقاء على حجم 24 لكل حديث يتسع في صفحة مستقلة.
- اختيار أكبر حجم صالح بدقة نصف نقطة للأحاديث التي تتجاوز صفحة كاملة فعلًا.
- نقل الحديث إلى صفحة جديدة بدل تصغيره لملء فراغ الصفحة السابقة.
- إضافة تحقق نهائي من عدم انقسام الحديث بعد إدراج فواصل الصفحات.
- تسريع القياس عبر اختبار عدة أحجام في عملية تصيير واحدة.
- إضافة إعادة محاولة آمنة لتصيير LibreOffice عند التعليق أو انتهاء المهلة.

## 1.1.0 — 2026-07-16

- إلغاء الجداول بالكامل من متن Word واستخدام فقرات حرة قابلة للتحرير.
- إضافة حدود سوداء كاملة حول صناديق عناوين الكتب والأبواب مع الإبقاء على التعبئة الخضراء.
- توسيع التلوين الخمري ليشمل سلسلة الرواة كاملة.
- ضمان تلوين متون جميع الروايات التابعة باللون البني الغامق.
- إضافة تنسيق المصطلحات: المصطلح والنقطتان Bold، والمعنى دون تغيير.
- إضافة قياس فعلي وتصغير آلي لخط الحديث الطويل حتى يبقى في صفحة واحدة.
- جعل تقسيم الأجزاء كل 20 صفحة تحققًا صارمًا، مع السماح للجزء الأخير فقط أن يكون أقصر.
- إضافة `format_hadith_batch.py` لمعالجة عدة ملفات مرقمة بالتوازي ودمجها عالميًا.
- إضافة دورات إصلاح تلقائية وتقارير وسيطة لكل كتاب قبل الدمج.
- منع إنشاء ملف نهائي ناقص أو إسقاط كتاب فاشل بصمت.

## 1.0.0

- الإصدار الأول لمحرك حذف الحواشي والمحافظة الحرفية وإنشاء Word مطابق للقالب.
