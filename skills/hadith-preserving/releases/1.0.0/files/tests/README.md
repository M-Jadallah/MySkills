# الاختبارات

تشغيل جميع الاختبارات:

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

الاختبارات الأساسية لا تحتاج LibreOffice، أما اختبارات تصغير الخط وتقسيم الأجزاء فتحتاج LibreOffice وPyMuPDF.

التغطية تشمل:

- حذف الحواشي وأرقام الصفحات.
- المحافظة الحرفية على النص.
- تلوين سلسلة الرواة كاملة.
- تلوين جميع متون الروايات.
- تنسيق المعاني.
- غياب الجداول وحدود الصندوق الأخضر.
- تصغير الحديث الطويل إلى صفحة واحدة.
- بدايات الأجزاء الدقيقة.
- ترتيب ودمج عدة ملفات مرقمة.
