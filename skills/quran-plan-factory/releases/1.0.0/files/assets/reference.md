# مرجع الخطة الأم — دلالات البنية (للوكيل، لا يُوزَّع على المستخدم)

هذا المرجع يوثق بنية الخطة المنهجية الأم كما حُلّلت وتحققت برمجياً. اللقطة
`master_plan.csv` لقطة مجمّدة عنها (1074 يوماً متصلة 1–1074، 604 صفحات مغطاة
بلا تكرار أو فجوة، النقاط الخام 52,422 والموزونة 74,199).

## أنماط بنود «خطة التسميع»
| النمط | المعنى | النقاط/الوزن |
|---|---|---|
| رقم صفحة (مثل `305`) | حفظ صفحة جديدة | 30 / 1 |
| `دوري` | مراجعة استعادية متجددة بلا نطاق محدد | 30 / 0 |
| `من [س-ص]` (مثل `من [1-10]`) | مراجعة تراكمية من بداية الكتلة حتى اليوم (إيقاع النصف الثاني) | 20 / 0 |
| `تسميع (س-ص)` | مراجعة تراكمية من بداية الجزء (إيقاع الأجزاء 28–30) | 60–180 / 0 أو 1 إذا ≥120 |
| `سورة X تراكمي` / `تسميع سورة X` | شهادة سورة | متغيرة / 2 إذا ≥70 وإلا 1 |
| `جزء N تراكمي` | شهادة جزء | 400 / 2 |
| `تسميع الجزء` / `تسميع جزء ونصف` / `تسميع الجزئين` | شهادة جزء/جزئين (النصف الثاني) | 100 / 2 أو 3 |
| `(a+b+c)` | شهادة ثلاثية أجزاء | 600 / 3 |
| `تسميع جزء قد سمع/تبارك/عم تراكمي` | شهادة أجزاء 28/29/30 | 600 / 2 |
| `تسميع جزء عمّ + جزء تبارك + قد سمع` | الشهادة الكبرى لثلاثية 28+29+30 | 600 / 3 |
| `تسميع سورة البقرة/آل عمران/النساء/المائدة/الأنعام/الأعراف/التوبة` | شهادات السور الكبرى (منفرد) | 500–1500 / 3 |

## الإيقاعات الثلاثة
1. **الأجزاء 16–27** (الأيام 1–405): صفحتان يومياً + يوم «دوري» بعد كل صفحتين،
   شهادة سورة عند نهاية كل سورة و«جزء N تراكمي» عند نهاية كل جزء.
2. **الأجزاء 28–30** (الأيام 406–508): 3 صفحات ثم مراجعة كتلة ثم مراجعة تراكمية
   من بداية الجزء تنمو تدريجياً (60→90→120→150→180).
3. **الأجزاء 1–15** (الأيام 509–1074): صفحة يومياً + مراجعة تراكمية «من [س-ص]»
   يومية متبادلة، وشهادات سور كبرى كبيرة النقاط.

- الأيام 101 و150 و216 أيام «دوري» أُضيفت بتصحيح موثق لإكمال إيقاع
  (صفحتان ثم دوري) — تظللها بالأصفر محفوظ في الخطة المخصصة أيضاً.

  وقد تسبق اكتمال السورة بصفحة أو تليه — تُنقل كما هي ولا تُعدَّل.

  اصطلاح الخطة الداخلي نفسه.
