# منسّق الأحاديث الحرفي — الإصدار 1.0.0

حزمة إنتاجية لتحويل مادة حديثية خام بصيغة TXT إلى Word منسق، مع حذف الحواشي وأرقام الصفحات دون تغيير الحروف أو الحركات في السند والمتن.

## ما الذي تفعله الحزمة؟

- تحذف كتل الحواشي حتى عندما تقطع الحاشية حديثًا بين صفحتين.
- تعيد وصل الجزء الذي سبق الحاشية بالجزء الذي يليها.
- تحذف أرقام إحالات الحواشي مثل `(1)` و`(14)`.
- تستبدل `صلى الله عليه وسلم` بـ`ﷺ` فقط.
- تترك عبارات `رضي الله عنه` وصيغها كما هي.
- تكتشف عناوين الكتب والأبواب.
- تكتشف الأحاديث المرقمة وتحافظ على أرقامها.
- تنشئ Word مطابقًا للهوية المرجعية.
- تمنع انقسام الحديث بين صفحتين، إلا إذا كان أطول من صفحة كاملة.
- تنشئ رأس جزء جديد في الصفحات 21 و41 و61... مع استمرار ترقيم الصفحات.
- تنتج تقرير تدقيق آلي وبصمات SHA-256.

## المتطلبات

- Python 3.10 أو أحدث.
- LibreOffice متاح في `PATH` باسم `libreoffice` أو `soffice`.
- خط Traditional Arabic مثبت على الجهاز الذي سيفتح أو يعرض الملف.

> لا تتضمن الحزمة أي ملفات خطوط.

## التثبيت

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows
# .venv\Scripts\activate

pip install -r requirements.txt
```

## الاستخدام

```bash
python scripts/format_hadith.py "input.txt" "output.docx"
```

مع تحديد الملفات المساندة:

```bash
python scripts/format_hadith.py "input.txt" "output.docx" \
  --clean-txt "output.clean.txt" \
  --audit-json "output.audit.json"
```

## الملفات المرجعية

- `references/reference-format.docx`: ملف Word الذي استُخرجت منه إعدادات الصفحة والألوان والخطوط.
- `reports/reference-analysis.json`: المواصفات الرقمية المستخرجة من المرجع.
- `examples/raw-example.txt`: عينة المادة الخام.
- `examples/formatted-example.docx`: ناتج تجريبي تمت معاينته بصريًا.
- `examples/formatted-example.audit.json`: تقرير التحقق للعينة.

## سياسة المحافظة على النص

المقارنة الحرفية تتجاهل اختلافات المسافات والأسطر فقط، لأنها عناصر تخطيط. أما الحروف والحركات وعلامات الترقيم فتبقى محفوظة بعد تطبيق قائمة التحويلات المصرح بها. إذا ظهر اختلاف آخر يتوقف السكربت بخطأ.

## اكتشاف الحواشي

لا يعتمد السكربت على حذف كل ما يقع بين خطين. بل يجزّئ النص حسب سطر رقم الصفحة، ثم يحذف كتلة تبدأ بفاصل ويعقبها رقم حاشية. وهذا يمنع حذف تكملة حديث بدأت في الصفحة التالية.

## التقسيم إلى أجزاء

يُنشأ ملف أولي بعلامات قياس غير مرئية، ثم يحوَّل إلى PDF بواسطة LibreOffice، وتُستخرج الصفحات الفعلية. بعد ذلك تُنشأ فواصل أقسام Word بحيث يبدأ:

- الجزء الأول: الصفحة 1.
- الجزء الثاني: الصفحة 21.
- الجزء الثالث: الصفحة 41.

تتكرر العملية حتى تستقر الحدود. اختُبر المحرك على ملفات تتجاوز 40 صفحة.

## خيارات سطر الأوامر

```text
--config PATH          إعدادات التنسيق.
--audit-json PATH      مكان تقرير التدقيق.
--clean-txt PATH       مكان النص المنظف.
--workdir PATH         الاحتفاظ بملفات القياس المؤقتة للتشخيص.
--skip-pagination      تجاوز القياس الفعلي؛ للاستكشاف فقط وليس للإنتاج.
```

## ملاحظات إنتاجية

- يجب فحص ملف Word بصريًا بعد التوليد على البيئة المستهدفة، لأن توفر الخط ومحرك العرض يؤثر في توزيع الأسطر.
- الحواشي غير الموسومة بنمط واضح لا تُحذف تلقائيًا؛ المحافظة على النص مقدمة على الحذف التخْميني.
- إذا ظهر نص توضيحي غير مثبت أنه حاشية، يبقى في الناتج بالأسود.
