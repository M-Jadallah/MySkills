# تعليمات توليد نماذج تنسيق دراسة التفسير

أُنشئت النماذج الخمسة بأداة توليد الصور المدمجة، للمفاضلة بين التصاميم. النصوص التوضيحية لا تمثل دراسة تفسيرية منجزة.

## 1. العلمي الكلاسيكي

الصورة: tafsir-design-1.png

```text
Use case: productivity-visual.
Asset type: visual concept of an editable Microsoft Word page for an Arabic Quranic exegesis study.
Create ONE high resolution portrait image showing exactly ONE complete A4 document page, straight-on and flat, crisp legible Arabic typography, no perspective, no desk, no laptop, no hands, no props. The document should almost fill the portrait image. This is an INTERIOR STUDY PAGE, not a book cover or a poster.
All text is right-to-left, in elegant readable Traditional Arabic / Naskh type with clear vocalization. Body typography is large and comfortable like Traditional Arabic 22pt, generous line spacing, realistic academic document density. A single main column, no Latin text. Use tasteful hierarchy and formatting that can realistically be recreated with Word paragraph styles, paragraph shading, simple borders, and tables. Include clear separation of quotes and source labels. Avoid excessive decorative imagery, illegible microtext, invented scholarly quotations, extra verses or prose.
Use EXACTLY this sample text in the layout, following this hierarchy:
Small top label: "نَمُوذَجٌ لِلتَّنْسِيقِ"
Main title: "دِرَاسَةُ الْآيَةِ ١١٩ مِنْ سُورَةِ التَّوْبَةِ"
Quran verse, prominently set in a pale green box: "﴿يَا أَيُّهَا الَّذِينَ آمَنُوا اتَّقُوا اللَّهَ وَكُونُوا مَعَ الصَّادِقِينَ﴾"
Section 1 heading: "١. خُلَاصَةُ التَّفْسِيرِ"
Body: "تُعْرَضُ هُنَا خُلَاصَةُ تَفْسِيرِ الْآيَةِ فِي فِقْرَةٍ وَاضِحَةٍ، مَعَ تَشْكِيلِ الْكَلِمَاتِ وَتَنْظِيمِ الْمَعَانِي."
Section 2 heading: "٢. أَقْوَالُ الْمُفَسِّرِينَ وَتَرْجِيحَاتُهُمْ"
Bold subheading: "اسْمُ التَّفْسِيرِ"
Quote sample: "«يُوضَعُ هُنَا نَصُّ الْقَوْلِ الْمَنْقُولِ مِنَ الْمَصْدَرِ، مَعَ الْمُحَافَظَةِ عَلَى أَلْفَاظِهِ وَتَوْثِيقِهِ.»"
Small source line: "الْمَصْدَرُ: اسْمُ الْكِتَابِ، الْجُزْءُ وَالصَّفْحَةُ."
Section 3 heading: "٣. الْمُصْطَلَحَاتُ الْعِلْمِيَّةُ وَشَرْحُهَا"
Three compact rows or paragraphs labelled: "الْمُصْطَلَحُ" / "التَّعْرِيفُ وَالشَّرْحُ" / "مِثَالٌ تَوْضِيحِيٌّ".
Footer note: "نَصٌّ تَوْضِيحِيٌّ لِعَرْضِ التَّنْسِيقِ"
Centered page number: "١".
Keep content, sequence and typography density comparable to the other variants. The image must clearly demonstrate a practical Word layout for long Arabic scholarly text.
DESIGN 1, CLASSICAL SCHOLARLY. Pure white page, dark red section headings, brown quotation marks and source labels, black body. Narrow double hairline page border in muted brown. Centered main title, understated horizontal rules, plain continuous text rather than cards, pale sage verse panel. Restrained, formal traditional Arabic scholarly publication, print friendly. Make the small top label also display "النَّمُوذَجُ ١".
```
