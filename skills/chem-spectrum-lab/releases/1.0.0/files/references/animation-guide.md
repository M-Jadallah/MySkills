# دليل الأنيميشن الخرافي — مختبر الطيف للكيمياء

الهدف: **تجربة "واو" على سطح المكتب** مع **أداء سلس على الجوال**. الأنيميشن يُقسَّم إلى مستويين حسب الجهاز.

## كشف الجهاز (device tier)
`shared/device.js` يحدد `TIER`:
- `epic` (سطح المكتب): `(pointer:fine)` + عرض ≥ 1024 + لا مسّ (maxTouchPoints===0)
- `lean` (جوال/لمس): أي جهاز لمس أو عرض < 1024

كل الأنيميشن تستدعي `window.LabFX.<effect>(el, opts)` الذي يتحقق من `TIER` قبل التنفيذ.

## المستوى الخرافي (DESKTOP / epic) — مطبّق بقوة
| التأثير | الآلية | التوقيت |
|---------|--------|---------|
| **شاشة البداية → المختبر** | انتقال شاشة كاملة: تلاشي + انزلاق + توهج كهربائي | 700ms |
| **توهج جزيئي** | Canvas particles (كهرباء زرقاء) خلف منطقة العمل | مستمر |
| **ظهور الأدوات** | Staggered spring (تأخير 60ms لكل أداة) + scale+rotate | عند الدخول |
| **سحب وإفلات** | أثر ضوئي خلف العنصر + اهتزاز ناعم عند الإفلات | لحظي |
| **تفاعل كيميائي** | انفجار فقاعات (Canvas) + تغيير لون تدريجي + shake خفيف | عند التفاعل |
| **المعادلة** | كتابة حرفية متحركة (typewriter) + توهج | عند الظهور |
| **الرسوم البيانية** | رسم متحرك للمسار (line draw) + نبض عند نقطة الذروة | عند التحديث |
| **النجاح** | burst نجوم/شرارات (Canvas confetti) + شعاع ضوئي | عند الإنجاز |
| **الشرح المختصر** | انبثاق زجاجي (glassmorphism) + blur-in | عند الحاجة |
| **شريط التقدم** | ملء متوهج متدرج + شرارة عند الاكتمال | مستمر |

مكتبات مسموح بها: **Canvas 2D** فقط (لا WebGL ثقيل). CSS `filter: drop-shadow` + `@keyframes` للتوهج.

## المستوى الخفيف (MOBILE / lean)
- تلاشي بسيط (fade) ومظهر تدريجي (appear) فقط.
- لا particles، لا confetti، لا shake.
- انتقالات شاشة = slide سريع 250ms.
- يُحافَظ على 60fps عبر تقليل `will-change` والاعتماد على compositor.

## قواعد صارمة
- ❌ Three.js / WebGL معقد (يقتل أداء الجوال).
- ❌ فيديوهات ثقيلة.
- ❌ React/Vue/Angular.
- ✅ Canvas 2D + CSS animations + SVG.
- ✅ الفرع حسب الجهاز عبر `device.js` — لا تعطيل كلي للأنيميشن على سطح المكتب من أجل الجوال.
- ✅ كل الألوان من هوية المختبر (`--c-primary:#00D4FF` الخ).

## كيف تستخدمه المنسّق
