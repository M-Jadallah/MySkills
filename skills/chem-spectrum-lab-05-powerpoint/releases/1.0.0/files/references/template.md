# هيكل السلايدات المطلوب — الدرس [الرقم]

| # | السلايد | المحتوى |
|---|---------|---------|
| 1 | **الغلاف** | عنوان الدرس + "مختبر الطيف للكيمياء" + اسم المدرس + الشعار |
| 2 | **الأهداف** | الأهداف التعليمية (3–5 أهداف) |
| 3 | **التمهيد** | المقدمة/السياق |
| 4-... | **المحتوى النظري** | فقرة فقرة مع الصور والرسومات |
| ... | **المعادلات** | كل معادلة بصيغة جميلة |
| ... | **الجداول** | جداول الخصائص والمقارنات |
| ... | **الأمثلة** | كل مثال محلول خطوة بخطوة |
| ... | **التجارب** | وصف التجارب مع الصور |
| ... | **التمارين** | الأسئلة والتمارين |
| الأخير | **الختام** | "انتقل للمختبر التفاعلي" + رابط الموقع + تواصلي |

```

│ [صورة/رسم]              [معادلة/جدول]                │

└────────────────────────────────────────────────────────┘
```

## Animations (نسخة العرض فقط)
| العنصر | Animation | التوقيت |
|--------|-----------|---------|
| العنوان | Fade In | عند ظهور السلايد |
| النقاط | Appear واحدة واحدة | عند الضغط |
| الصور | Zoom In | بعد النص |
| المعادلات | Wipe من اليسار | عند الضغط |
| الجداول | Fade In | كاملة |

❌ لا يُستخدم: Morph، انتقالات بين السلايدات، فيديوهات مدمجة.
