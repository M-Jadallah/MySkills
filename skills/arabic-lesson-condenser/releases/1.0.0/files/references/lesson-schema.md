# مخطط lesson.json (JSON Schema Reference)

اكتب ملف JSON الوسيط بهذا الشكل الحرفي بالضبط، ثم تحقق بـ `python scripts/validate_input.py --input lesson.json` وابنِ بـ `python scripts/build_docx.py --input lesson.json --output lessons_output/<اسم>.docx`.

## الحقول الجذرية

| الحقل | النوع | إلزامي | ملاحظات |
|---|---|---|---|
| `title` | نص | نعم | عنوان الدرس، مشكول بالكامل، يُعرض Heading 1 أحمر مركزيًا |
| `subtitle` | نص | لا | سطر تعريفي بني تحت العنوان (سلسلة الدرس مثلًا) |
| `sections` | قائمة | نعم | محاور الدرس بترتيبها، غير فارغة |

## الحقول داخل كل محور (section)

| الحقل | النوع | إلزامي | ملاحظات |
|---|---|---|---|
| `heading` | نص | نعم | عنوان المحور، يُعرض Heading 2 أحمر قابل للطي |
| `blocks` | قائمة | لا (الافتراضي `[]`) | محتوى المحور — أنواعها أدناه |
| `subsections` | قائمة | لا (الافتراضي `[]`) | نفس بنية المحور: `heading` + `level` (عدد صحيح ≥ 2) + `blocks` + `subsections` متداخلة |
| `section_summary` | نص | لا | **تجنّبه عادة** — المستند كله صياغة مختصرة أصلًا؛ إن استُخدم يظهر بعنوان "◆ خُلَاصَةُ القِسْمِ" |
| `table` | كائن | لا | `{title, headers, rows}` — عند الحاجة فقط (قواعده في rewriting-rules.md §4) |
| `concept_map` | كائن | لا | `{label, children}` — عند الحاجة فقط (قواعده في rewriting-rules.md §5) |

## أنواع البلوكات (blocks)

| النوع | الحقول | الوصف |
|---|---|---|
| `paragraph` | `text` | فكرة/مسألة كاملة بصياغتك، مشكولة |
| `evidence` | `text` | **دليل منقول نصًا** (آية/حديث/نقل) — يُعرض بتظليل أخضر فاتح وخط أخضر غامق تلقائيًا؛ لا تضف زخارف يدويًا |
| `bullet_list` | `items` | قائمة عناصر غير مرتبة (`•` تلقائي) |
| `numbered_list` | `items` | قائمة مرتبة (`١.` `٢.`... تلقائي) |

```json
  "subtitle": "سِلْسِلَةُ بَابِ الْعِلْمِ — الدَّرْسُ الْأَوَّلُ",
  "sections": [
    {
      "heading": "فِي فَضْلِ الْعِلْمِ وَمَنْزِلَتِهِ",

        {"type": "paragraph", "text": "الْعِلْمُ عِبَادَةٌ يَقْرُبُ بِهَا الْعَبْدُ مِنْ رَبِّهِ، وَأَوَّلُ مَا نَزَلَ مِنَ الْوَحْيِ كَانَ أَمْرًا بِالْقِرَاءَةِ، وَفِي ذَلِكَ دَلِيلٌ عَلَى شَرَفِ الْعِلْمِ وَمَنْزِلَتِهِ."},
        {"type": "evidence", "text": "قَالَ اللَّهُ تَعَالَى: ﴿اقْرَأْ بِاسْمِ رَبِّكَ الَّذِي خَلَقَ﴾ [الْعَلَقُ: ١]"},
        {"type": "evidence", "text": "وَقَالَ ﷺ: «مَنْ سَلَكَ طَرِيقًا يَطْلُبُ فِيهِ عِلْمًا سَلَكَ اللَّهُ بِهِ طَرِيقًا مِنْ طُرُقِ الْجَنَّةِ» (رَوَاهُ مُسْلِمٌ)"},

        }
      ],
      "table": {
        "title": "مَنَازِلُ طَالِبِ الْعِلْمِ",

          ["الثَّانِيَةُ", "التَّخَصُّصُ بِالْعُلُومِ النَّافِعَةِ"]

      },
      "concept_map": {
        "label": "طَلَبُ الْعِلْمِ",
        "children": [
          {"label": "أَدِلَّتُهُ", "children": ["آيَةُ اقْرَأْ", "حَدِيثُ طَرِيقِ الْجَنَّةِ"]},

    {
      "heading": "نِيَّةُ طَلَبِ الْعِلْمِ",
      "blocks": [

    }
  ]

```

## تنبيهات سريعة

1. كل النصوص مشكولة تشكيلًا كاملًا وﷺ وأرقام عربية.
2. لا تكرّر نص الصياغة حرفيًا داخل الجدول أو الخريطة — لا تقفز بين المواضع بلا ترتيب.
3. عدد الخلايا في كل `rows[i]` = عدد `headers` بالضبط.
4. عنوان عقدة الخريطة ≤ ١٦٠ حرفًا، وعمق التداخل ≤ ٦.
5. بعد الكتابة: `validate_input.py` ثم `build_docx.py` — بوابة التسليم في SKILL.md.
